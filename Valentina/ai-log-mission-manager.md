## Context

My team received a proposal with five missions (character, dialogue, objective and learning for each one, plus two "Did you know...?" facts). In this conversation, Claude wrote the prompt below based on that proposal and my HUD scripts, and then used it to generate the script. I did not write this prompt or this code from scratch; my part was defining the need, reviewing the result, adding it to the project, wiring it in Unity and testing it.

## Prompt used

```
I'm building a 2D Unity 6 (6000.6.7f1) educational game set in Bogotá in 1810. I already have a HUDController script with these public methods: SetMission(string), AddItem(string), RemoveItem(string), ShowFact(string title, string body) and CloseFact(). Please write a C# MonoBehaviour called MissionManager that drives five story missions.

Requirements:
1. All code, variable names and comments must be in English. Use a short comment on every field and method. Put "// Generated by AI" on the first line.
2. A serializable Mission class with: objective (short HUD text), learning (a historical fact), factTitle and factBody (an optional "Did you know...?" window).
3. A serialized array of the five missions, pre-filled with the Spanish texts I provide (mission proposal: objectives shortened for the HUD, learning and facts copied as written).
4. On Start, show the first objective with HUDController.SetMission.
5. A public method CompleteMission(int missionNumber) (1-based) that NPC dialogues can call. It must ignore the call unless it is the active mission, so missions cannot be completed out of order or twice.
6. When a mission is completed: show its learning in the fact window, wait until the player closes it (no time limits, WCAG 2.2.1), show the optional fact window the same way, and then show the next objective. After the last mission, show a final text.
7. Add a public bool IsFactOpen property to HUDController for the script to wait on.
8. Be null-safe: if the HUDController is not assigned, log a warning.
9. Also add a UnityEvent called onDialogueFinished to my Dialogue_NPC script, invoked when the last dialogue line closes, so each NPC can call CompleteMission from the Inspector.
Finally, explain in a few short steps how to wire it in Unity.
```

A second prompt was used later, after a problem found in testing (see "Error debugged with AI"):

```
When the pause menu is opened while an NPC is speaking, the dialogue text keeps typing (it uses unscaled time) and the learning window appears over the settings. Please make the dialogue freeze while the pause menu is open: add a static bool IsPaused to PauseMenuManager, a static bool IsDialogueActive to Dialogue_NPC, make the typing coroutine and the E key wait while paused, and make ResumeGame keep time frozen if a dialogue is still open. Keep all code and comments in English and mark every new line with "// Generated by AI".
```

## Error debugged with AI

- The text list slot showed a "not allowed" cursor when I dragged the dialogue panel. Cause: the slot accepts only objects with a TextMeshPro component, and I was dragging the panel, not its text child. Fix: found the exact object by clicking the Dialogue Text field of the NPC and dragged that one.
- I first looked for the dialogue script on a decorative NPC (`Npc_9`). Fix: the NPC with dialogue is the one that has a DialogueMark child (`Dama_1`).
- During testing, Unity froze once right after the learning window appeared. After restarting Unity, the same flow worked correctly and the freeze did not happen again; the cause is unknown.
- Found while testing: opening the pause menu while an NPC was speaking let the text keep typing and showed the learning window over the settings. Fix (AI-generated, implemented): `PauseMenuManager.IsPaused` and `Dialogue_NPC.IsDialogueActive` flags; the typing coroutine waits while paused, E is ignored while paused and ResumeGame keeps time frozen if a dialogue is still open. Tested: the dialogue freezes with the menu open and continues after resuming.
