5. Follow the style of my existing script below: public or serialized references to UI objects and a short English comment on every field and method.
6. Put "// Generated by AI" on the first line.
Finally, explain in a few short steps how to wire it in the Unity Inspector.

My existing script for style:

using UnityEngine;

public class PauseMenuManager : MonoBehaviour
{
   public GameObject PauseMenu; // Reference to the pause menu UI panel
   public GameObject PauseButton; // Reference to the button that opens the pause menu

   // Pauses the game time and swaps UI visibility
   public void PauseGame()
    {
        Time.timeScale=0; // Freezes game time
        PauseButton.SetActive(false); // Hides pause button
        PauseMenu.SetActive(true); // Shows pause menu
    }

    // Resumes the game time and restores UI visibility
    public void ResumeGame()
    {
         Time.timeScale=1; // Restores normal game time speed
        PauseButton.SetActive(true); // Shows pause button again
        PauseMenu.SetActive(false); // Hides pause menu
    }

    // Closes the application or stops play mode in the editor
    public void QuitGame()
    {
        Debug.Log("Closed Game");
        Application. Quit();
    }

}

## Error debugged with AI

The size buttons had no OnClick event. Cause: SizeSmall, SizeMedium and SizeLarge were created as plain TextMeshPro text objects, not as buttons, so they had no Button component. Fix: added a Button component to each and connected `SetTextSize(0/1/2)`.

Also, in the first 200% test the fact window title did not resize because it was missing from the list of texts to scale. Fix: added it to the list.
