## Prompt used

```
I'm building a 2D Unity 6 (6000.6.7f1) educational game set in Bogotá in 1810. Please write a C# MonoBehaviour called HUDController for the game's HUD, following the same style as the SettingsPanel script we wrote before (serialized references to UI objects, a short English comment on every field and method).

Requirements:
1. All code, variable names and comments must be in English. Use TextMeshPro (TMPro).
2. Mission: a public method SetMission(string mission) that updates a [SerializeField] TMP_Text missionText.
3. Inventory: public methods AddItem(string itemName) and RemoveItem(string itemName). Keep a List<string> and show it as a list, one item per line, in a [SerializeField] TMP_Text inventoryText. Show a configurable label when the inventory is empty. Do not add duplicates.
4. "Did you know...?" window: a public method ShowFact(string title, string body) that opens a [SerializeField] GameObject factPanel and fills a title and a body TMP_Text. It must have no timer: it stays open until the player closes it with a public CloseFact() method (for a UI button) or by pressing Enter. This is a WCAG 2.2.1 requirement (no time limits).
5. Other scripts (a mission manager and the audio system) will call these public methods, so keep them simple and null-safe.
6. Put "// Generated by AI" on the first line.
Finally, explain in a few short steps how to wire it in the Unity Inspector.
```
